# MyAI 多环境配置说明

## 📋 环境概览

| 环境 | 配置文件 | 数据库 | 用途 | 激活方式 |
|------|----------|--------|------|----------|
| **local** | `application-local.yml` | `my_ai` | 本地开发 | `spring.profiles.active=local` |
| **dev** | `application-dev.yml` | `my_ai_dev` | 开发环境 | `spring.profiles.active=dev` |
| **test** | `application-test.yml` | `my_ai_test` | 测试环境 | `spring.profiles.active=test` |
| **prod** | `application-prod.yml` | `my_ai_prod` | 生产环境 | `spring.profiles.active=prod` |

## 🔧 配置文件结构

### 主配置文件 (`application.yml`)
- 包含所有环境通用的配置
- 设置默认激活的环境
- 通用的服务器配置、API文档配置等

### 环境特定配置文件
每个环境都有独立的配置文件，包含：
- 数据库连接配置
- Redis 配置
- RabbitMQ 配置
- 日志级别配置
- 第三方服务配置

## 🚀 使用方法

### 1. 本地开发
```bash
# 方法1：修改 application.yml
spring.profiles.active=local

# 方法2：启动参数
java -jar myai.jar --spring.profiles.active=local

# 方法3：环境变量
export SPRING_PROFILES_ACTIVE=local
```

### 2. IDE 配置
在 IDEA 中设置 VM options：
```
-Dspring.profiles.active=local
```

### 3. Docker 部署
```yaml
environment:
  - SPRING_PROFILES_ACTIVE=prod
  - DB_USERNAME=your_db_user
  - DB_PASSWORD=your_db_password
```

## 📊 环境特性对比

### Local (本地开发)
- ✅ 详细的 SQL 日志输出
- ✅ 热重载功能
- ✅ 调试级别日志
- ✅ 本地数据库连接
- ❌ 不需要 HTTPS

### Dev (开发环境)
- ✅ 适中的日志级别
- ✅ 开发服务器连接
- ✅ 文件日志记录
- ❌ 不显示详细 SQL

### Test (测试环境)
- ✅ 测试数据库
- ✅ 模拟生产环境配置
- ✅ 性能监控
- ❌ 有限的日志输出

### Prod (生产环境)
- ✅ 高性能数据库连接池
- ✅ 安全的 HTTPS 配置
- ✅ 环境变量配置
- ✅ 日志文件轮转
- ✅ 监控端点
- ❌ 最小化日志输出

## 🔐 安全配置

### 生产环境安全特性
1. **环境变量配置**：敏感信息通过环境变量传入
2. **HTTPS 强制**：Cookie 安全标志启用
3. **日志脱敏**：不输出敏感信息
4. **监控端点**：仅暴露必要的监控信息

### 环境变量列表
```bash
# 数据库配置
DB_USERNAME=your_db_user
DB_PASSWORD=your_db_password

# Redis 配置
REDIS_HOST=your_redis_host
REDIS_PASSWORD=your_redis_password

# API 密钥
LANGCHAIN_API_KEY=your_langchain_key
AI_API_KEY=your_ai_key
SEARCH_API_KEY=your_search_key
```

1. **开发阶段**：使用 `local` 环境
2. **功能测试**：使用 `dev` 环境
3. **集成测试**：使用 `test` 环境
4. **生产部署**：使用 `prod` 环境

## 🔄 环境切换

### 快速切换脚本
```bash
#!/bin/bash
# switch-env.sh

case $1 in
  "local")
    export SPRING_PROFILES_ACTIVE=local
    echo "切换到本地开发环境"
    ;;
  "dev")
    export SPRING_PROFILES_ACTIVE=dev
    echo "切换到开发环境"
    ;;
  "test")
    export SPRING_PROFILES_ACTIVE=test
    echo "切换到测试环境"
    ;;
  "prod")
    export SPRING_PROFILES_ACTIVE=prod
    echo "切换到生产环境"
    ;;
  *)
    echo "用法: ./switch-env.sh [local|dev|test|prod]"
    ;;
esac
```

## 🐛 故障排查

### 常见问题
1. **配置文件不生效**：检查 `spring.profiles.active` 设置
2. **数据库连接失败**：验证对应环境的数据库配置
3. **日志级别不对**：确认环境特定的日志配置

### 调试命令
```bash
# 查看当前激活的配置
java -jar myai.jar --debug

# 查看配置属性
java -jar myai.jar --spring.config.location=classpath:/application-local.yml
```
